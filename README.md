niucloud-admin-java框架采用插件化模式设计，可以做到多种插件共存，组合使用。  
一切皆为插件（应用）！例如，您有一个项目需要商城功能、旅游项目销售、会员管理、客服系统等，传统的做法是东拼西凑或部署多套系统。

## 目录说明

```
niucloud-admin-java
  |- niucloud-addon == 插件模块 (JAVA)
  |- niucloud-boot == 框架启动模块 (JAVA)
  |- niucloud-core == 框架核心业务模块 (JAVA)
  |- niucloud-web-app == Web应用模块 (JAVA)
  |- uni-app == 手机端源代码（UNI-APP, HBUILDER）
  |- web == PC端源代码（VITE）
  |- admin == 管理端源代码（VUE3, VITE）
  |- webroot == 生产环境发布模块
  |  |- addon == 插件目录
  |  |- jar == jar包目录
  |  |- public == 前端编译后的代码目录
  |  |- resource == 资源文件目录
  |  |- runtime == 运行时目录
  |  |- niucloud.bat == Windows启动文件
  |  |- niucloud.sh == Linux启动文件
```
